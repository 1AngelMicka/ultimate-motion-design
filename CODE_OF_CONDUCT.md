# Code of conduct · Code de conduite

Be kind, be precise, assume good faith. Critique the work, never the person. No harassment, insults or discrimination of any kind, in issues, pull requests or any other space of this project.

Sois bienveillant, précis, et pars du principe que l'autre est de bonne foi. On critique le travail, jamais la personne. Aucun harcèlement, insulte ou discrimination, dans les issues, les pull requests ou ailleurs dans le projet.

Report a problem privately to the maintainer through a GitHub security advisory or the contact on the maintainer's profile. Reported content is removed and repeat offenders are blocked.

Signale un problème en privé au mainteneur (avis de sécurité GitHub ou contact du profil). Le contenu signalé est retiré, et les récidivistes sont bloqués.
