> **Comment lire ce catalogue :** certains dépôts sont des **skills à installer** dans Claude/Codex, d’autres sont des **bibliothèques, logiciels ou modèles** à leur faire utiliser par code. Un dépôt n’est pas nécessairement gratuit pour tous les usages : vérifie sa licence, ses API éventuelles et ses prérequis matériels avant de l’intégrer.

## Installer un skill dans Claude Code ou Codex

Pour un dépôt qui **publie effectivement des Agent Skills compatibles**, commence par regarder ses instructions puis, lorsque proposé :

```bash
npx skills add <owner/repo>
```

Exemples :

```bash
npx skills add remotion-dev/skills
npx skills add LottieFiles/motion-design-skill
npx skills add greensock/gsap-skills
npx skills add heygen-com/hyperframes
```

Un MCP, un logiciel de montage, une bibliothèque JavaScript ou un modèle IA **ne s'installe pas nécessairement** avec cette commande. Lis son `README.md`.

Documentation supplémentaire : [animer une timeline GSAP dans Remotion](https://www.remotion.dev/docs/gsap/use-gsap-timeline).

## Précautions pratiques

- **Licences :** Remotion possède des conditions commerciales spécifiques ; `anything2explainer` est sous licence non commerciale, `react-bits` inclut une Commons Clause et Rubber Band peut exiger une licence commerciale selon l'usage.
- **Coûts :** Fal.ai, Higgsfield, les modèles génératifs et les TTS tiers peuvent facturer les générations.
- **Sécurité :** inspecte scripts, permissions, accès réseau et secrets avant d'installer un skill ou un serveur MCP.
- **Compatibilité :** tous les outils ne fonctionnent pas nativement sur Windows ; certains exigent Blender, After Effects, GPU, FFmpeg, Chrome, Node.js ou Python.
- **Pièges de licence :** le SPDX de GitHub ne suffit pas. Le code est souvent sous MIT alors que les poids sont non commerciaux (F5-TTS, MusicGen, YuE2, MMAudio, FLUX.1-dev, LivePortrait, CodeFormer). Les modèles Tencent Hunyuan sont inutilisables en France, car leur licence exclut l'Union européenne. Tout ce qui tourne sur Remotion hérite de sa licence, même un dépôt MIT comme snapcn ou un kit de captions. L'AGPL interdit d'embarquer le code dans un outil sous licence permissive (OpenChatCut, DepthFlow, whisper-timestamped) ; la GPL ne gêne que si tu redistribues le code (pedalboard, Geometry Script, binaires ffmpeg-static). easings.net est sous GPL : à citer, pas à copier. Animate UI ajoute une Commons Clause qui interdit la revente. Un dépôt sans licence se cite ou s'installe à part, mais ne se copie pas.
- **Portée :** sélection large et organisée, **pas une prétention à l'exhaustivité mondiale**. Les dépôts évoluent ou changent de nom ; les descriptions et liens doivent être revérifiés avant installation.
